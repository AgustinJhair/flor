# Para ti Iris

Página estática para compartir con WhatsApp o publicar en GitHub Pages.

## Archivos

- [index.html](index.html): página principal

## Publicar en GitHub Pages

1. Crea un repositorio en GitHub.
2. Sube este archivo `index.html`.
3. En el repositorio, ve a `Settings` > `Pages`.
4. En `Source`, selecciona `Deploy from a branch`.
5. Elige la rama principal (`main`) y la carpeta raíz `/`.
6. Guarda.
7. GitHub te dará una URL como:
   `https://usuario.github.io/nombre-del-repositorio/`

## Compartir por WhatsApp

Una vez publicado, puedes enviar ese enlace directo a ella desde Android.

Ejemplo:

```text
https://usuario.github.io/nombre-del-repositorio/
```

## Vista local

Puedes abrirlo localmente en el navegador con:

```bash
# Windows
start index.html
```

O simplemente abre el archivo en tu navegador.
